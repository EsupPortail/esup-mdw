# Notes de migration — changements d'API des controllers (pour les agents vues)

> Produit par l'agent controllers/exports. À lire AVANT de porter une vue.

## Nouveau type pour les exports

`fr.univlorraine.mondossierweb.utils.DownloadFile` : `record DownloadFile(String fileName, byte[] content, String mimeType)` + `getInputStream()`, `getContentLength()`, constantes `MIME_TYPE_PDF`, `MIME_TYPE_XLSX`.

La vue branche un téléchargement Flow ainsi (pattern) :
```java
DownloadFile df = controller.exportPdf(...);           // peut être null (erreur/non autorisé)
anchor.setHref(DownloadHandler.fromInputStream(evt ->
    new DownloadResponse(df.getInputStream(), df.fileName(), df.mimeType(), df.getContentLength())));
```

## Signatures changées

- `CalendrierController.exportPdf()` : retourne `DownloadFile` (null si erreur)
- `InscriptionController.exportPdf(Inscription)` → `DownloadFile`
- `NoteController.exportPdfResume()` / `exportPdfDetail(Etape)` → `DownloadFile`
- `SsoController.exportQuittancePdf(Etudiant, Inscription)` / `exportAffiliationSsoPdf(Etudiant, Inscription)` → `DownloadFile`
- `ListeInscritsController.getPdfStream(...)` (InputStream) / `getXlsStream(...)` (ByteArrayInputStream) : retours inchangés MAIS `ComboBox listeGroupes` remplacé par `Map<String,String> libellesGroupes` (clé=cléGroupe, valeur=libellé) dans `getXlsStream(...)` et `creerExcel(...)`.
- `EtudiantController.getAnneeUnivRes()`, `getAnneeUnivEnCours()`, `getAnneeUnivEnCoursToDisplay()` : SANS paramètre (état lu via SessionController).
- `ListeInscritsController.recupererLaListeDesInscrits(Map<String,String>, String annee)` et `recupererLaListeDesInscritsELP(Map, String)` : plus de paramètre GenericUI ; l'état (listeInscrits, anneeInscrits, etapeListeInscrits, listeGroupesInscrits…) est écrit dans `SessionController`.
- `RechercheController` : `accessToRechercheArborescente(code, type)`, `accessToDetail(code, type, annee)` conservés — navigation Flow avec query parameters `code`/`type`/`annee`. Constantes de routes : `ROUTE_RECHERCHE_ARBORESCENTE="rechercheArborescenteView"`, `ROUTE_LISTE_INSCRITS="listeInscritsView"`, `ROUTE_ETAT_CIVIL="etatCivilView"`, `ROUTE_ERREUR="erreurView"`. Supprimés : `accessToMobileDetail(...)`, `accessToMobileNotesDetail(Etape)`.
- `UiController` (refonte) : `registerUI(com.vaadin.flow.component.UI)` / `unregisterUI(UI)` — À APPELER DEPUIS MainLayout (onAttach/onDetach) ; `getUis()` → `List<UI>` ; `sendNotification(String message)` ; `killUser(UserDetails)`, `killSession(VaadinSession)`, `killUI(UI)`. Supprimés : `sendMessage()`, `confirmKill*`, `confirmRemoveLock` → AdminView affiche un ConfirmDialog/Dialog de saisie puis appelle killUser/killSession/killUI/`lockController.removeLock(lock)` ou `sendNotification(texte)`.
- `UserController.canCurrentUserAccessView(Class)` SUPPRIMÉ → utiliser `ViewSecurityService.isAccessGranted(ui, VueX.class)` (menu) et `@Secured` sur les vues.
- `Utils` : supprimés `isViewDesktop/isViewMobile/isViewEnseignant`, `setButtonStyle`, `ajoutLogoBandeau*` (à recréer dans MainLayout si besoin) ; `getLibelleFromComboBox(String, ComboBox)` → `getLibellesFromCodes(String codes, Map<String,String> libelles)`.
- `IPhoto` : interface inchangée (types neutres).
- `DateToStringConverter` : implémente `com.vaadin.flow.data.converter.Converter<String, Date>`.
- `ReferencedButton` : porte un Button Flow.

## Deep linking (DeepLinking.java supprimé)

Créer des routes Flow pour préserver les URLs publiques :
- `accesDossierEtudiant/:codEtu` → utilise `RechercheController.accessToDossierEtudiantDeepLinking(codEtu)` (ou `accessToDetail(code, ETU, null)`)
- `adminView` → AdminView.

## Divers

- Injection de `SessionController` dans un singleton : `@Autowired @Lazy` (proxy résolu à l'appel).
- `LockController.getLockOrNotify` affiche une Notification Flow (LUMO_CONTRAST) — nécessite un thread UI.
- `entities/vaadin/ObjetBase` toujours utilisé par `RechercheArborescenteController.getObj(...)` : conserver.
- Les routes Flow reprennent les ANCIENS noms de vues @SpringView (ex: "notesView", "inscriptionsView", "adminView"...) pour préserver les URLs.
